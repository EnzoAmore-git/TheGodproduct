# TheGodProduct — личный сайт-портфолио

Сайт продуктового архитектора / Fractional CPO — Дениса Захаренкова.
Одностраничный сайт (landing) для продажи консалтинговых услуг: аудит продукта,
Design Ops, Fractional Product Lead.

Проект собран из модулей: HTML без инлайновых стилей и скриптов, CSS разбит по
компонентам, JS — по ответственности. Стек: **Vite + ES-модули**, без сторонних
UI-библиотек.

---

## Требования

- Node.js 18+ и npm

## Быстрый старт

```bash
npm install       # установка зависимостей (Vite)
npm run dev       # dev-сервер с hot reload → http://localhost:5173
npm run build     # сборка статики в папку dist/
npm run preview   # локальный предпросмотр собранной версии
```

> Страница использует ES-модули, поэтому просто открыть `index.html` двойным
> кликом **не получится** — нужен http-сервер (`npm run dev` или `npm run preview`).

## Деплой

- **Хостинг (thegodproduct.ru):** выполнить `npm run build` и выложить содержимое
  папки `dist/` в веб-корень (на Beget это `public_html/`).
- **GitHub Pages:** сначала изменить `base` в `vite.config.js` на `'./'`
  (или `'/<имя-репозитория>/'`), затем собрать и опубликовать `dist/`.

## Как это работает

**CSS.** Порядок подключения в `<head>` важен: `variables → reset → typography →
layout → components/* → animations`. Дизайн-токены (цвета/шрифты/радиусы) лежат в
`variables.css`; остальные файлы используют `var(--...)`.

**JS.** Единственная точка входа — `js/main.js` (`<script type="module">` в конце
`<body>`). Каждый модуль экспортирует `init*()`-функцию и не трогает глобальную
область. `analytics.js` подключается первым (side-effect import).

**Мобильное меню.** На ширине ≤ 700px ссылки навигации скрываются, появляется
кнопка `.nav-burger` (`data-nav-toggle`). Клик переключает класс `.is-open` на
`<nav>`, открывая панель `[data-nav-menu]`. Меню закрывается по клику на пункт,
по `Escape`, по клику вне меню и при возврате к десктопной ширине.

**Анимации.** `animations.js` через `IntersectionObserver` добавляет карточкам
анимацию `fadeUp` при появлении в вьюпорте. Если включена системная настройка
«уменьшить движение», анимации отключаются (см. `animations.css`).

## Как добавить новую секцию / страницу кейса

1. Создайте `css/components/<имя>.css` и подключите его в `<head>` после
   остальных компонентов.
2. Добавьте разметку в `index.html` (секцию — по образцу существующих).
3. Если нужна своя JS-логика — создайте `js/<имя>.js` с функцией `init*()` и
   вызовите её из `main.js` внутри `init()`.

## Заметки по рефакторингу

- Источник — `reference/index_old.html` (монолит с инлайновым CSS/JS и base64-картинками).
- Base64-изображения вынесены в `assets/images/` (HTML стал легче примерно в 7 раз).
- Убраны инлайновые стили, `<style>` и `<script>`; аналитика вынесена в отдельный модуль.
- Добавлено мобильное меню (в оригинале навигация на мобильных просто скрывалась).
- Удалён неиспользуемый («мёртвый») код: классы `.skill-list/.skill-item/.skill-name/.skill-bar/.skill-fill`
  и связанная с ними анимация — в разметке таких элементов нет.
- В текстах сохранены авторские формулировки как есть. Найденные опечатки
  (`консистентности,Обеспечил`, `сфокусом`, `chekout`) не исправлялись — оставлены
  на усмотрение владельца, чтобы не менять контент при рефакторинге.
- `reference/index_old.html` — локальная резервная копия оригинала (в git не коммитится).
